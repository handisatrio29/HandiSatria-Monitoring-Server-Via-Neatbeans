# 🖥️ Manajemen Jadwal Monitoring Server

Aplikasi desktop berbasis Java yang digunakan untuk mengelola dan menjadwalkan aktivitas monitoring server secara terstruktur.

## 🎯 Tujuan Aplikasi
Membantu administrator atau tim IT dalam:
- Mengatur jadwal monitoring server
- Mendokumentasikan aktivitas monitoring
- Meminimalisir kesalahan pencatatan jadwal monitoring

## 🛠️ Teknologi yang Digunakan
- Java (Swing GUI)
- NetBeans IDE
- File Storage CSV (tanpa database)

## ✨ Fitur Aplikasi
- Menampilkan daftar jadwal monitoring server
- Menambahkan jadwal monitoring (Create)
- Menghapus jadwal monitoring (Delete)
- Validasi input data
- Penyimpanan data otomatis ke file CSV

## 📂 Struktur Project
MonitoringJadwalServer
├── data
│ └── jadwal_monitoring.csv
├── Source Packages
│ └── monitoringjadwalserver
│ ├── Jadwal.java
│ ├── CSVHelper.java
│ ├── MainFrame.java
│ └── Main.java

## ▶️ Cara Menjalankan
1. Buka project di NetBeans
2. Pastikan file `jadwal_monitoring.csv` ada di folder `data`
3. Jalankan `Main.java`
